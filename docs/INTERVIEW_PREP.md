# Interview Preparation

**Author:** Kanishk Gupta

Write your own answers. Update these prompts if schema discovery changes the available analysis.

1. What lending business problem does EMI Tachometer address?
2. How did you establish the dataset schema before writing transformations?
3. How did you choose and validate data types in the staging layer?
4. Which date parsing and invalid-date handling decisions did you make?
5. How did you parse duration strings and validate edge cases?
6. How did you standardize categorical values without erasing meaningful distinctions?
7. How did you decide how to handle missing values for each field?
8. How are LTV, loan-to-asset ratio, vintage, and risk bands defined?
9. How do you define a default rate, its denominator, and exposure at risk?
10. How did you control for low volume when comparing branches or states?
11. How do the SQL analyses distinguish association from causation?
12. How did you construct and validate the rule-based risk segments?
13. How might the selected thresholds create fairness or operational risks?
14. What does the logistic regression baseline add, and what can its AUC not tell you?
15. What additional repayment and outcome data would you need before recommending production use?
